# NetPractice

## Description
This project is a general practical exercise designed to introduce the basics of computer networking. [cite_start]The main goal is to configure small-scale networks by fixing issues related to IP addressing and routing to ensure proper communication between devices[cite: 14, 15].

[cite_start]The project consists of 10 levels of increasing difficulty where we must manually configure IP addresses, subnet masks, and routing tables for hosts, routers, and switches[cite: 68].

## Instructions

### Installation & Execution
1.  Download the project files and extract them into a folder.
2.  You can run the "index.html" file and use it in either evaluation or training mode.

### Usage
1.  **Login:** Enter the intranet login (`beciftci`) in the login field on the main page. [cite_start]This is crucial for generating the correct configuration for evaluation[cite: 84, 224].
2.  **Solving Levels:** Modify the empty fields (IPs, masks, routes) until the network behaves correctly.
3.  [cite_start]**Exporting:** Once a level is solved, click the **"Get my config"** button to download the configuration file for that specific level[cite: 139].

### Networking Concepts
[cite_start]This project relies on the understanding of the following core networking concepts[cite: 208]:
* **TCP/IP Addressing:** Understanding IPv4 address classes and structure.
* **Subnet Masks & CIDR:** Calculating network ranges and splitting networks into subnets.
* **Default Gateways:** Configuring exit points for traffic destined for outside networks.
* **Routers and Switches:** Understanding the difference between switching and routing forwarding.
* **Routing Tables:** Static routing and next-hop configuration.
* **OSI Layers:** Troubleshooting connectivity based on network layers.
